# ADR 002: deterministic financial truth, bounded advisory AI

Accepted. Integer aggregation and policy rules decide match status. AI reads scoped aggregates,
never SQL/HTTP chosen by the model, never writes finance, never submits a proposal. Schema and
citation gates reject malformed reports. Human proposals and independent supervisors close cases.
Tradeoff: lower autonomy and more review effort in exchange for auditable, testable boundaries.
Citation availability does not establish semantic support; semantic support remains ungraded. The live 48-case raw-evidence holdout scored 37.5%,
reinforcing the deterministic-finance boundary; see the evaluation report.
